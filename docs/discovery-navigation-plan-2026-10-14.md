# 直觀探索與品牌家族改版

## 問題與目標

使用者指出：BEAMS 只列 BOY、關係清單難以閱讀、全站不知道從哪裡開始。目標是在第一屏提供具體選擇與下一步，補全官方標籤索引，讓品牌關係服務穿搭和逛店。

## 執行

1. 官方 BEAMS 索引核對名稱、服裝範圍、現行／終了狀態；優先標籤另核對官網概念。
2. 首頁改為直接說明日本服飾品牌用途，五個入口：男裝、女裝、風格、預算、地區。雙品牌真實圖片作輔助。
3. /relationships 改為先選家族的卡片索引，各家族獨立內容，不一次展開全部清單；BEAMS 用「怎麼挑」分組和完整官方名稱索引。
4. /brands/beams/labels 提供完整家族導覽；其他關係依自有標籤、同公司、合作線與面料／系列分區，保留精確來源。
5. /areas 加入首批已核對門市的城市／街區入口，明示範圍；不假設一家店販售所有標籤。
6. 建置、目視桌面／手機、家族切換與分類直連、來源／圖片及正式發布檢查。無自動化測試套件新增／執行。

## 成功條件

- 初次讀者能從明確需求開始；首頁第一屏有可點擊入口。
- BEAMS 主要標籤有名稱、用途、服裝範圍和商品入口；完整索引包含官方其他專案、選貨店及歷史項目，不一概稱子品牌。
- 全頁字級可讀、無標題被導覽蓋住或超長空白清單；手機無橫向溢出。
- 延續免費個人靜態 Vercel，不新增付費依賴；保留既有品牌和使用者 Git 修改。
