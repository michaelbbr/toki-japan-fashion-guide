- Preserve the user's nine new brands and commit history. Resolve the invalid build entry with a real static builder; configuration belongs in vercel.json.

- Reduce the homepage to clear entry points and selected content. Put the complete 15-entry catalog on the index; use uniform photo ratio, type hierarchy and spacing.

- Same-company brands, sublabels, collaboration lines, fabric suppliers and product series are distinct relationships. PURPLE LABEL receives a separate page; URBAN RESEARCH and JOURNAL STANDARD relatives each have a named relationship row.

- Continue existing free static personal Vercel Hobby deployment. No purchases, subscriptions, paid image processing, database, analytics, paid API or domain. Revisit hosting terms before any monetization.

Recheck when sources change, imagery breaks, new official product/price evidence appears or commercial scope is requested. Source references and uncertainties: docs/brand-and-photo-audit-2026-10-14.md.

## 2026-10-14 — Start with a reader's decision

- User feedback overrides the previous poetic first-screen copy and long relationship list. Start with clothing scope and clear actions: men, women, style, budget and place. Photos support these actions.
- Family hub leads to one brand at a time. BEAMS official index is fully represented as 35 names, with 14 introductory directions and a compact additional/ended index. Other families clearly state limited audited coverage instead of implying a complete company catalog.
- Source names and end state come from official pages. Clothing labels, selected brands, concept stores and cultural projects retain different identities. Official label photography is explicitly distinguished from exact representative SKU imagery; selected outfits may contain third-party brands.
- A first regional index may publish partial verified coverage when counts and scope are explicit. Use real store addresses and gender-specific counters; no invented inventory, universal label availability, opening hours or travel duration. Map search links need no paid map API.
- Improved typography and a solid sticky header help orientation; grouping links land below the header. Do not combine scroll padding and large anchor margins to add unnecessary gaps.

Reconsider after actual reader feedback, official label/store changes or expansion to more verified brand/region records. No usability success/conversion metric is claimed from a visual review.

## 2026-10-15：旅行購衣新手優先
- 使用者明確目標為不熟日本服飾、旅日時想知道哪些牌子可買的台港旅客。首頁主動線改成四步選品牌；品牌名索引、支線研究放在後續深入入口。
- 性別、風格、品類、預算分開；撤下混合性別和店型的 shelf 選單。預算是單件日圓參考，排除歷史款配對，不推定全品牌價帶。
- 風格用具名真實單品示例及白話問題；所有步驟可選不限。地區資料不足時誠實提供範圍及官方入口，不能把缺資料寫成當地無店。
- 不新增收費服務，沿用既有 GitHub／Vercel Hobby 靜態部署。

## 2026-10-15 使用者修正：首頁先說清楚，功能按情境放置
- 首頁只承擔定位與開始動作；以「幫我挑品牌」為主要CTA，全部品牌為次要入口。原功能仍保留於品牌頁、地區頁與新購衣指南 /guide，不再首頁全部堆疊。
- 品牌圖是穿搭理解工具，改用具名真人穿搭照；代表單品區繼續使用精確實品圖。圖像不證明全套商品歸屬、價格或庫存；歷史影像保留年份。
- 目錄不再預設只顯示12品牌。風格捷徑直接把結果帶進視窗，名稱索引可展開，所有50個品牌卡保留。引導結果仍分批6張，清楚標示總數且有繼續入口。
